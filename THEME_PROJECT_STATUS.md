Theme project status — 2026-09-29

Assessment of `stripe/stripe-android` at `3543d1dde0faecb7664bed12e4a402df51db30f7`, which matched GitHub master during the investigation. PR states and check results below are a snapshot as of September 29, 2026.

The core scoped-appearance migration is largely merged, but the project is not ready to call complete. Live icon updates, remaining consumers of global appearance, and public API rollout still need work.

Also inspected both open diffs, current CI/review status, current source, the linked API review, and the relevant unlabelled Address Element PR. Unresolved GitHub thread flags alone are not evidence of unfinished work: several merged PRs retain explanatory or answered threads.

The approved goal is to give merchants `Automatic`, `AlwaysLight`, and `AlwaysDark` through `PaymentSheet.Appearance.Builder.themeMode()`, scoped to PaymentSheet, Embedded Payment Element, CustomerSheet, and Address Element. The [API review](https://docs.google.com/document/d/1-mjWQoaNe4v-NlpaX-MjZMXvLRKLslwKFNOq7Hc2oU4/edit) was approved for GA on July 14. Separately, the implementation replaces process-wide mutable appearance values with appearance owned by each UI instance, preventing one instance from supplying another instance's styling.
