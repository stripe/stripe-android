Summary: Copying the Android Checkout Elements integration guides into an app fails compilation: the guides use nonexistent CheckoutController APIs and treat configure() as Kotlin Result although the SDK returns CheckoutElementsController.OperationResult. A merchant cannot complete the documented controller setup without reverse-engineering the current API.
